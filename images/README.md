# Gallery photos

Drop your photos here using these exact filenames (any .jpg/.png works, just
keep the name and rename your file to match):

- double-room.jpg   — a double sharing room
- dining.jpg        — common dining area
- study-corner.jpg  — study area
- triple-room.jpg   — a triple sharing room
- building.jpg       — building exterior

Once a file is in this folder, it'll show up on the site automatically —
no code changes needed. Until a photo is added, that spot shows a plain
placeholder pattern instead.
